# Outfitters – E-Commerce Website

## Project Overview

Outfitters is a simple, responsive e-commerce fashion website developed as part of a Web Technologies assignment. It includes a homepage displaying different fashion products and a separate product details page.
The website is designed using HTML, CSS, and Bootstrap 5. It focuses on creating a clean layout, product cards, navigation bar, and responsive design for different screen sizes.

## Technologies Used

- **HTML5:** Used to create the structure of the website.
- **CSS3:** Used for custom styling, colors, spacing, hover effects, and responsive adjustments.
- **Bootstrap 5.3.3:** Used for the responsive navbar, grid system, cards, buttons, and form controls.
- **Google/Unsplash Images:** Used to display product images.

## Website Pages

### 1. Homepage (index.html)

The homepage includes:
- Navigation bar with the Outfitters logo, Home, Products, Contact, and Cart links.
- Promotional banner with a "Shop Now" button.
- New Arrivals section displaying 8 fashion products.
- Product images, names, prices, and Add to Cart buttons.
- Footer containing the website name and copyright information.

### 2. Product Details Page (product.html)

The product page displays:
- Product image.
- Product name and price.
- Short product description.
- Quantity selection field.
- Add to Cart button.
- Footer.

## Responsive Design

Bootstrap's grid system and CSS media queries are used to make the website responsive.
The product grid adjusts according to screen size:

- **Desktop:** 4 products per row.
- **Tablet:** 3 products per row.
- **Mobile:** 2 products per row.

The navigation bar also collapses into a hamburger menu on smaller screens using Bootstrap's responsive navbar component.
Additional mobile styling adjusts banner padding, heading sizes, product image heights, and button text sizes.

## Conclusion

This project demonstrates the use of HTML, CSS, and Bootstrap to develop a responsive e-commerce website. It provides practical experience with webpage structure, Bootstrap components, CSS styling, navigation, product grids, and responsive layouts.
